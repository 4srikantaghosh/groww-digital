# groww Digital Website

A responsive, multi-page static website built with HTML, CSS and vanilla JavaScript.

## Files
- index.html
- about.html
- services.html
- portfolio.html
- pricing.html
- contact.html
- css/style.css
- js/script.js
- assets/

## Before publishing
1. Replace the placeholder phone number, WhatsApp number and email in `contact.html`.
2. Replace sample portfolio items with real work and verified results.
3. Update pricing to your actual packages.
4. Replace the Google Maps location if your office is elsewhere.
5. Replace the FormSubmit endpoint email with your real receiving email.
6. If desired, replace the Google Fonts import with locally hosted fonts.

## Free deployment
Upload the entire folder to a GitHub repository and enable GitHub Pages, or import the repository into Vercel/Cloudflare Pages.
